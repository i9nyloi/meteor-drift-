# Meteor Drift

A tiny endless arcade game about dodging a meteor shower. Built with plain HTML, CSS, and JavaScript; no install or build step required.

## Play locally

Open `index.html` in a browser. Use the left and right arrow keys or A/D to steer. On a touch screen, press and drag across the game area. Dodge meteors for as long as you can. Your best score stays in this browser.

## Publish with GitHub Pages

1. Create a GitHub repository and add these project files to its root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
4. Open the Pages URL shown in the settings after deployment finishes.
